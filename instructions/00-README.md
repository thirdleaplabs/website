# Website Redesign Workspace

This folder contains the complete website strategy and Antigravity build instructions for:

1. **Third Leap Labs** — corporate and investment-facing website
2. **Cognisense Cloud** — product and pilot-conversion website

## Confirmed brand structure

- **Company:** Third Leap Labs LLC
- **Company website:** https://thirdleaplabs.com
- **Product:** Cognisense Cloud
- **Brand signature:** Cognisense Cloud by Third Leap Labs
- **Product website:** https://cognisense.cam
- **Primary product category:** Cloud Visual Intelligence Platform

## Files

- `01-MASTER-ANTIGRAVITY-PROMPT.md` — central prompt controlling both redesigns
- `02-THIRD-LEAP-LABS-PAGE-BY-PAGE.md` — detailed corporate-site architecture and copy
- `03-COGNISENSE-CLOUD-PAGE-BY-PAGE.md` — detailed product-site architecture and copy
- `04-DESIGN-SYSTEM-AND-COMPONENTS.md` — colors, typography, layout, motion, and reusable components
- `05-CONTENT-ASSET-CHECKLIST.md` — screenshots, logos, diagrams, videos, legal links, and founder assets
- `06-LAUNCH-AND-QA-CHECKLIST.md` — pre-launch review and application consistency checks

## Recommended workflow

1. Read the master prompt.
2. Build Third Leap Labs first.
3. Build Cognisense Cloud second using the same shared design language.
4. Replace placeholders with real screenshots and verified facts.
5. Review both sites against the Qatar application before publishing.

## Core rule

The websites must support one clear investment narrative:

> Third Leap Labs is an applied AI company building Cognisense Cloud, a cloud and edge visual-intelligence platform for safety, security, and operational intelligence.

WhaleScanner and open-source work may appear as supporting portfolio evidence, but Cognisense Cloud must remain the flagship product for the Qatar application.
