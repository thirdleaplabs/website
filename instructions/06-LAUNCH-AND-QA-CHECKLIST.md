# Website Launch and QA Checklist

## Content consistency

- [ ] Third Leap Labs name is consistent.
- [ ] Cognisense Cloud name is consistent.
- [ ] “by Third Leap Labs” appears correctly on the product site.
- [ ] VisionX, Indus Vision and FlameTrax public references are removed.
- [ ] Company location and incorporation details are accurate.
- [ ] Founder biography matches the approved founder profile.
- [ ] Product stage matches the Qatar application.
- [ ] Customer, pilot, user and revenue claims match verified records.
- [ ] All feature claims are demonstrable or clearly qualified.
- [ ] Qatar/GCC expansion language matches the application commitment.

## Navigation and links

- [ ] Desktop navigation works.
- [ ] Mobile navigation works.
- [ ] Active states are correct.
- [ ] Third Leap Labs links to cognisense.cam.
- [ ] Cognisense links to thirdleaplabs.com.
- [ ] WhaleScanner links are correct.
- [ ] Social links are correct.
- [ ] Privacy and terms links work.
- [ ] No placeholder `#` links remain.
- [ ] No broken external links.

## Forms

- [ ] Required fields are identified.
- [ ] Labels are visible and accessible.
- [ ] Error messages are clear.
- [ ] Keyboard navigation works.
- [ ] Consent text is present.
- [ ] Spam protection is configured.
- [ ] Submissions reach the correct destination.
- [ ] Success state is visible.
- [ ] Failure state provides a recovery path.
- [ ] Sensitive form data is not logged unnecessarily.

## Responsive review

Test at minimum:

- [ ] 320 px mobile
- [ ] 375/390 px mobile
- [ ] 768 px tablet
- [ ] 1024 px tablet/small desktop
- [ ] 1440 px desktop
- [ ] Wide desktop

Check:

- [ ] No horizontal overflow.
- [ ] Headlines wrap intentionally.
- [ ] Buttons remain accessible.
- [ ] Dashboard visuals remain legible.
- [ ] Forms do not overflow.
- [ ] Sticky sections do not trap scrolling.
- [ ] Mobile menu can be closed.

## Accessibility

- [ ] One H1 per page.
- [ ] Heading hierarchy is logical.
- [ ] Landmark elements are used.
- [ ] Focus indicator is visible.
- [ ] All controls are keyboard operable.
- [ ] Informative images have alt text.
- [ ] Decorative images use empty alt text.
- [ ] Colour contrast is sufficient.
- [ ] Status is not communicated by colour alone.
- [ ] Reduced-motion preference is respected.
- [ ] Form errors are announced appropriately.

## Performance

- [ ] Hero assets are optimised.
- [ ] Below-the-fold images are lazy-loaded.
- [ ] Responsive image sizes are provided.
- [ ] Video is compressed and has a poster.
- [ ] Fonts do not block rendering unnecessarily.
- [ ] Unused JavaScript is removed.
- [ ] Layout shift is controlled.
- [ ] Core Web Vitals are reviewed.
- [ ] Third-party scripts are justified.

## Browser review

- [ ] Chrome
- [ ] Edge
- [ ] Safari
- [ ] Firefox
- [ ] iOS Safari
- [ ] Android Chrome

## SEO

- [ ] Unique page titles
- [ ] Unique meta descriptions
- [ ] Canonical URLs
- [ ] Open Graph metadata
- [ ] Social-preview images
- [ ] Sitemap
- [ ] Robots rules
- [ ] Structured data where appropriate
- [ ] Descriptive internal-link text
- [ ] Redirects from removed routes

## Security and privacy

- [ ] HTTPS enforced.
- [ ] No secrets in client code.
- [ ] No development endpoints exposed.
- [ ] Security headers reviewed.
- [ ] Form endpoints validate input.
- [ ] Cookie behaviour reviewed.
- [ ] Privacy policy reflects actual form and analytics use.
- [ ] Product screenshots contain no sensitive data.
- [ ] No unverified compliance badge is displayed.

## Production readiness

- [ ] Analytics configured.
- [ ] Error monitoring configured.
- [ ] 404 page works.
- [ ] 500/fallback behaviour is acceptable.
- [ ] Favicon and manifests are correct.
- [ ] Social previews tested.
- [ ] Deployment rollback path understood.
- [ ] Domain and DNS verified.
- [ ] Contact-form ownership confirmed.
- [ ] Final founder approval received.

## Qatar application alignment

- [ ] Website product name matches the F6S form.
- [ ] Website product description matches the pitch deck.
- [ ] Business model is not contradicted.
- [ ] Deployment claims match the architecture document.
- [ ] Founder and company facts match attachments.
- [ ] No claim implies an existing Qatar operation before it exists.
- [ ] Request-a-pilot flow is functional before evaluators visit.
